# 作业人员 V0.1 验收记录

## 已检查功能

- `src/roles/worker/pages/my-tasks.js` 无账号登录，通过人员选择器进入并可切换具体人员。
- 只按当前车辆和当前人员分配展示任务，显示计划时间、工位、同组人员和配件。
- 开始、完成及实际开始/结束时间记录。
- 完成后唯一生成一条质量待检记录。

## 本轮修复内容

- 严格限制状态流转为 `NOT_STARTED → IN_PROGRESS → COMPLETED`。
- 拒绝重复开始、未开始直接完成和重复完成。
- 拒绝未分配人员操作他人任务。
- 实际时间改为操作发生时的本地时间，不再复制计划时间。

公共动作修改位于 `src/core/actions.js`，原因是作业页与质量页共用任务状态和待检记录；质量阶段已回归。

## 测试结果

- 多人员选择入口和作业人员选择器：Edge 自动化通过。
- 本人开始、完成：通过。
- 非本人任务操作：拒绝。
- 重复操作保护：通过。
- 实际开始和结束时间：通过。
- 质量待检记录生成一次且不重复：通过。
