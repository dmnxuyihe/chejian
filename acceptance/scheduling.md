# 生产排程 / 调度人员 V0.1 验收记录

## 已检查功能

- 当前车辆选择、逐车生成 20 条任务、版本生成、任务锁定/解锁、重新排程和发布。
- `src/roles/scheduling/pages/dashboard.js`、`gantt.js`、`workforce.js`、`resources.js`、`exceptions.js` 的车辆级数据过滤和展示。
- 人员、设备、工位、配件实例的时间占用；班组人数、人员请假、FS 和 lag 约束。

## 本轮修复内容

- 将异常、发布状态和负荷统计改为按车辆读取，修复车辆 A 的异常阻止车辆 B 发布的问题。
- 第二辆车排程时读取其他车辆既有工位、人员、设备和配件占用，避免跨车重复占用。
- 重排某车时仅替换该车的自动分配，保留其他车辆的 schedule、version、人员、设备、配件和锁定任务。
- 修复锁定任务在重排中只保留显示时间、后续计算却使用新时间的问题；锁定时间违反硬约束时生成 `LOCK_CONFLICT`。
- 版本主键改为全局唯一 ID，版本号按车辆递增；各分配 ID 继续按全局最大值生成。
- 人员请假加入可用时间推迟计算。
- 修复发布按钮被两个监听器重复执行的问题。

公共排程动作位于 `src/core/actions.js`，修改原因是所有排程页面共用同一状态；回归覆盖计划、工班长、作业和质量链路。

## 当前仍未实现的高级排程功能

- 多车全局联合优化、技能约束、拖拽排程、方案对比、算法参数配置、局部实时重排。
- 当前逐车策略会避让已排车辆，但不会重新优化所有车辆的总体完工时间。
- 当前工位初始化容量均为 1；算法未实现容量大于 1 的并行工位槽位。
- 配件里程匹配、FIFO 和完整生命周期规则未实现。
