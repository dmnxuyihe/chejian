# 全页面图形界面覆盖

2026-10-30。保持深灰蓝与青绿主题，全部绘图均为项目原生SVG，文字、数量、状态仍来自实际页面和数据库。

覆盖18个角色、145个路由。435次明暗主题/手机一致性检查，加上290次768/1280宽度图形检查，共725次。修复监控页中等宽度的网格溢出。

其中112个待开发页面只完成视觉、功能范围图和导航统一，继续保留待开发标识；本次没有将它们改报为已完成业务。

## 共用组件

- 导航：职责图标、角色位置提示、原有完整功能抽屉。
- 页面：15类业务图形、统一标题层次和操作区。
- 数据：实际值的统计卡片、带分类图形的台账、统一表格边界。
- 查询：车辆信息分组，工位完成环与真实任务数对应。
- 状态：空状态插图、待开发功能范围图、加载/连接失败提示。
- 弹窗：对应业务图标、统一字段区域，保留关闭和键盘焦点逻辑。

- `tests/workspace_ui.py`：页面、菜单、模板键盘操作、弹窗焦点、375/390/768/1024/1440布局。

- `tests/workspace_graphics_ui.py`：145路由、290次图形覆盖/中等宽度检查。
