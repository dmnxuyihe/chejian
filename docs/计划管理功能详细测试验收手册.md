# 计划管理功能详细测试验收手册

## 1. 文档用途

本文用于逐页面验收本次新增和调整的计划管理功能，覆盖：

- 年度计划管理与年度交验统计；
- 月度计划日历、计划列表和年度/月度计划导入；
- 计划完善与统计中的年度、月度和配件月计划；
- 配件下车、上车计划；
- 整车临修计划；
- 配件临修计划；
- 月度计划、整车临修、配件临修和配件上车计划审批；
- JSON 模拟存储、刷新恢复、删除提示、导入预览与纠错；
- 标题栏、切换按钮和导航合并后的样式一致性。

建议测试人员按本文顺序执行。涉及审批状态的测试具有前后依赖，不建议跳过前置步骤。

---

## 2. 测试环境与准备

### 2.1 启动系统

1. 在项目目录启动服务。
2. 浏览器访问：`http://127.0.0.1:5193/`。
3. 等待月度计划页面完整显示，不应一直停留在“正在加载”。
4. 建议使用 Chrome 或 Edge，并将浏览器缩放设置为 100%。

### 2.2 测试文件

| 用途 | CSV 文件 | XLSX 文件 |
| --- | --- | --- |
| 年度/月度混合导入与纠错 | `docs/年度月度计划导入混合示例.csv` | 无 |
| 整车临修计划导入 | `docs/整车临修计划模拟导入.csv` | `outputs/planning-import-samples/整车临修计划模拟导入.xlsx` |
| 配件临修计划导入 | `docs/配件临修计划模拟导入.csv` | `outputs/planning-import-samples/配件临修计划模拟导入.xlsx` |
| 配件月计划导入 | `docs/配件月计划模拟导入.csv` | `outputs/planning-import-samples/配件月计划模拟导入.xlsx` |

CSV 和同名 XLSX 内容一致。建议先用 XLSX 验证 Excel 导入，再用 CSV 验证兼容性。

### 2.3 初始模拟数据预期

首次打开系统时，如果计划相关 JSON 集合为空，系统会自动补充一次演示数据：

| 数据分类 | 预期模拟数据 |
| --- | --- |
| 年度计划调整 | 2026 年多个自然月的年初计划、调整后计划、实际进车和工艺天数 |
| 配件月计划 | 2026-11 的上车、下车计划 |
| 月度交验 | 1 条已通过记录 |
| 整车临修 | 1 条待审核、1 条草稿 |
| 配件临修 | 1 条待审核、1 条草稿 |
| 审批中心 | 1 条整车临修待审核、1 条配件临修待审核 |

初始化只执行一次。后续由测试人员删除的数据不会在每次刷新时自动恢复。

### 2.4 测试记录方法

每个测试项执行后填写：

- 结果：`通过 / 不通过 / 阻塞`；
- 实际现象；
- 截图编号；
- 缺陷编号。
