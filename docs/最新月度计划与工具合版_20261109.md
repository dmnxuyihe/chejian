## 工具管理继承了哪些优点

1. **状态能直接识别。** 在库、借出、送检送修、待审核、停用与盘亏等状态使用颜色和文字一起表达，原始数据筛选和导出口径不变。
2. **突出当前后续动作。** 待审核工具突出“审核申请”，检修中突出“登记检修结果”，调拨中突出“接收调拨”，避免在一排按钮中寻找下一步；所有操作仍在台账下方。
3. **办理范围明确。** 跨查询保留选择时，明确提示当前筛选外还有几项工具会一起办理。批量后续办理实时显示勾选单数、数量；空选不能提交，未选单据状态不变。
4. **审核前看依据和影响。** 同一审核弹窗展示申请人、申请时间、原因、盘点/借用/检修来源和数量。批准显示账面变化，驳回明确不扣账；无需在多个页面往返核对。

保留前一轮的8项修复：盘亏冻结可借量、跨盘点防重复扣减、部分失败独立停用、拆分来源履历、设备数量校验、套装调拨限制、正确回执、异常处置与待办分离。

## 合并时额外修复的冲突

- 新月度服务原先直接写审批及车辆表，未推进全站数据版本。现与导入、工具命令使用同一事务锁，并在事务中更新版本，旧页面保存返回冲突而不会覆盖新审批记录。
- 月度操作成功后先重新加载共享数据库状态，再刷新月度视图，避免拿旧审批数据继续保存。
- 修复月度申请明细约束重复初始化报错；重复启动和数据库重新连接可正常执行。
- 月度申请的 `WITHDRAWN` 与工具处置审核的状态规则分别验证，月度撤回不破坏工具操作。
