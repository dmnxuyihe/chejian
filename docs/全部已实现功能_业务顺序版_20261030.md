# 全功能演示：按业务接力顺序讲清楚

先沿同一组两辆车，完成一项代表任务的业务闭环；再集中展示维护和边界功能。主线建议30—45分钟，补充功能按实际操作预留时间。

基础资料 → 两车计划 → 资源核对 → 模拟调整 → 正式发布 → 班组派工 → 实际接车 → 作业执行 → 检修记录 → 质量确认 → 管理复盘

主线结束后再做补充A—F。不要把新增删除、故意制造冲突穿插在现场作业中。

| 段落 | 当前角色 | 交付给下一步的结果 |
| --- | --- | --- |
| 1. 开场：这次要完成什么 | 讲解者 | 观众知道接下来处理哪两辆车、由谁接力。 |
| 2. 事前条件：检修按什么工艺、用什么资源 | 技术工艺人员 / 资源管理人员 | 工艺依据和资源来源交代清楚。 |
| 3. 计划人员接单：导入两车、核对入段日期 | 计划管理人员 | 两车已入库，可在月度日历查到；尚未正式排程。 |
| 4. 调度接单：选两车、设期限、核对资源 | 生产调度人员 | 两车和最晚日期已确定，资源预检通过。 |
| 5. 先试排再调整：模拟、锁定和重算 | 生产调度人员 | 得到检查通过的模拟方案，人工指定时段被保留。 |
| 6. 正式下发：方案变成班组任务 | 生产调度人员 → 工班长 | 40项正式任务和默认4份班组清单可查。 |
| 7. 班组落地：组长换人、增员 | 工班长 / 组长 | 同一正式任务完成换人和增员，当前执行人员明确。 |
| 8. 现场前提：记录真实入段与上台 | 现场记录人员 | 计划与实际时间分开显示，车辆实际进场有记录。 |
| 9. 现场执行：同一任务开始、完成，监控同步 | 作业人员 / 车间管理人员 | 代表任务从未开始→进行中→已完成，生成待检记录，其他窗口可读取。 |
| 10. 作业留痕：说明、检测数据、图片与视频 | 作业记录人员 | 代表任务有检测数据和附件，刷新可读取。 |
| 11. 质量确认：完成作业不等于检查通过 | 专检 / 验收人员 | 同一项任务已完成、已提交资料、质量结果为通过。 |
| 12. 管理复盘：同一数据，从单车看到整个车间 | 车间管理人员 / 生产调度人员 | 月度计划、班组任务、个人执行、检修记录、质量结果和车间查询能互相核对。 |

遇到问题：取消模拟、故意制造截止日期不足等边界演示放在补充C，避免打断这条主线。

## 主线11 · 质量确认：完成作业不等于检查通过
