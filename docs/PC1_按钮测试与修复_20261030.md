# PC1 按钮测试与修复记录

测试日期：2026-10-30。范围为当前 PC1 演示中已实现的业务入口。写入、删除、发布和附件上传均使用独立 PostgreSQL 测试 schema；未清空或重置演示数据库。

## 本次发现并修复

| 问题 | 修复结果 |
| --- | --- |
| 右上角菜单点击报 `role is not defined`，无法进入日计划发布与任务下发 | 导航绑定传入当前角色；鼠标点击、SVG 图标点击和键盘 Enter 均能跳转 |
| 设备选择“未分配”工位后保存失败 | 空工位写为 SQL NULL，有工位时使用数字编号 |
| 工具检修周期、上次检修时间和备件出厂日期字段未正确映射到对应数据库列 | 保存时同步到数据库映射使用的字段，编辑时读取实际数据库字段 |
| 工具数量小数或无效日期提交到数据库才失败 | 保存前提示错误，表单保留；可选日期留空可以保存 |
| 计划列表选择月份后刷新丢失 | 在当前浏览器会话保存列表月份、年度和导入类型 |
| 切换年度/月度后列表仍显示切换前结果 | 切换时重新按年度/月度来源查询数据库 |
