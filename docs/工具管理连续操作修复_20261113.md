# 工具管理连续操作修复（2026-11-13）

对应本轮调研报告 F01–F07，保持原有六个工具子页与业务范围。

| 问题 | 完成后的行为 |
| --- | --- |
| F01 入库时间偏移 | 带时区时间先转为本机时间显示和编辑；没有修改的时间保留原值、秒和毫秒精度。最后检修/检定日期同样保留未改动的原值，纯日期保持纯日期。新增及修改后的时间明确保存时区。单项与批量编辑均处理。 |
| F02 时间口径不一致 | 工具台账、档案、业务记录、操作日志、盘点、看板、设施通信与业务导出共用时间显示函数，和本机时间查询一致。旧的无时区记录保持原有墙上时间含义，不做猜测性历史迁移。 |
| F03 查询草稿丢失 | 已应用条件与输入草稿分别维护。勾选、排序、表头筛选不吞掉草稿，待查询提示继续显示；未应用的条件仍不能用于办理或导出。 |
| F04 切页上下文丢失 | 本次会话中，各工具子页分别记住已应用条件、草稿、选择及表格位置。台账刷新恢复会话存储；从预警等显式来源进入时使用来源条件，重置后刷新不恢复旧来源限定。 |
| F05 删除日志缺少身份 | 新操作日志保存操作前后的对象快照，包括名称、编号、工具库、数量及基础字段；删除和批量删除可按原编号查询，操作名称为中文，可打开前后变更明细。变更后编号与历史编号均可识别。 |
| F06 数量错误难定位 | 借出/调拨/送检/送修等数量输入显示可办理上限，错误标记在对应行并聚焦。多人并发导致余量改变时不自动重提，更新余量和状态，保留其他输入，要求用户核对后再确认。 |
| F07 未归还组合查询 | “业务记录 → 借还”内可同时按工具库、借用类型、未归还状态筛选；包含工具和套装，并排除已结清和其他库的记录。套装借用显示套装名称和编号；条件与 CSV 使用同一查询。其他业务类型隐藏借还专用条件。 |

删除确认同时列出具体对象，并说明页面无法直接恢复；未增加回收站模块。旧日志未保存的对象快照无法凭空补齐，会明确标记历史信息不足，不将现有台账错当作历史事实。已有备份的恢复方式保持不变。
