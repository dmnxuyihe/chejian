# 年度 / 月度检修计划导入示例

此示例用于说明模板列的填写格式和预览校验结果。机车编号、配属信息是占位数据，不能直接确认导入；正式导入前请替换为真实业务数据。本例将下方计划列表筛选设为2026年11月，但月度导入的入段日期可以属于任意月份。

## 模板文件

在“计划管理人员 → 月度计划同步与编制”下载 XLSX 或 UTF-8 BOM CSV 模板。XLSX 包含“导入数据”和“填写说明”工作表；请只在“导入数据”表填写。两种导入类型使用相同字段：

| 列名 | 必填 | 示例 | 实际校验规则 |
| --- | --- | --- | --- |
| 机车编号 | 是 | `示例勿导入001` | 必须是文本，非空，最多64字符；数字格式会报错，避免丢失前导零 |
| 机型 | 是 | `HXD1C` | 非空，最多64字符；必须匹配数据库中的有效机型 |
| 修程 | 是 | `HXD1C高级修` | 非空，最多64字符；必须是该机型对应的有效修程 |
| 修次 | 否 | `2` | 留空可以；填写时必须为正整数，例如 `1`、`2`，`0`、负数、小数均报错 |
| 计划入段日期 | 是 | `2026-11-03` | 必须是实际有效日期；支持 Excel 日期、`YYYY-MM-DD`、`YYYY/MM/DD`；只有年度导入才限制在所选年份内 |
| 配属局 | 否 | `示例铁路局` | 留空可以，最多64字符 |
| 配属段 | 否 | `示例机务段` | 留空可以，最多64字符 |
| 累计走行公里 | 否 | `123456.5` | 留空可以；须在 `0` 到 `99999999999.9` 之间，最多1位小数，不能使用千位分隔符 |
| 备注 | 否 | `正确样例勿导入` | 留空可以，最多500字符 |

## 混合正确与错误的 CSV 样例

```csv
机车编号,机型,修程,修次,计划入段日期,配属局,配属段,累计走行公里,备注
示例勿导入001,HXD1C,HXD1C高级修,2,2026-11-03,示例铁路局,示例机务段,123456.5,正确字段样例勿导入
,HXD1C,HXD1C高级修,1,2026-11-04,,,,机车编号为空
示例勿导入003,不存在的机型,HXD1C高级修,,2026-11-05,,,,机型不在有效字典
示例勿导入004,HXD1C,不存在的修程,,2026-11-06,,,,修程与机型不匹配
示例勿导入005,HXD1C,HXD1C高级修,0,2026-11-07,,,,修次必须是正整数
示例勿导入006,HXD1C,HXD1C高级修,,2026-02-30,,,,无效日期
示例勿导入007,HXD1C,HXD1C高级修,,2026-12-01,,,,月度导入允许其他月份
示例勿导入008,HXD1C,HXD1C高级修,,2026-11-08,,,123.45,公里数最多1位小数
```

### 预览时应看到什么

- 第2行是字段格式正确的示例。它仍可能因数据库中已有相同检修计划或同车同修程有未完成计划而被标记冲突；系统会在预览和确认时检查数据库。
- 第3至第7行和第9行演示机车编号必填、机型字典、修程与机型匹配、修次、无效日期和公里数精度错误。第8行的日期属于2026年12月，月度导入仍应通过月份校验，因为月度导入不限制入段月份。
- 请勿对本示例点击“确认导入”。如需熟悉操作，可先上传查看预览，再点击“取消预览”；取消不会写入任何业务数据。

## 字段以外的文件校验

- 必须包含四个必填表头：机车编号、机型、修程、计划入段日期。必填表头缺失或任意表头重复属于文件级错误，文件不能生成预览。
- 标准表头以模板为准。未识别的额外列会提示并忽略，不会写入系统字段；完全空白行会忽略，预览行号仍对应原始文件行号。
- XLSX/XLS 明确读取“导入数据”工作表；“填写说明”不会作为数据读取。业务字段单元格不能使用公式，公式不会执行。
- CSV 必须是 UTF-8（模板为 UTF-8 BOM）。若出现乱码或不支持的编码，请另存为 CSV UTF-8 后重试。
- 文件最大5 MB、最多1000条非空数据行、最多100列。错误明细 CSV 会对潜在公式内容做安全处理。
- 文件内相同机车、修程、入段日期且内容完全相同的重复行：保留首条，后续行标记重复。识别键相同但内容不同，相关行标记冲突。同车同修程不同日期也会提示核对计划调整。
- 数据库已有相同机车、修程、入段日期的计划会报错；同车同修程有未完成计划但日期不同会提示冲突。本功能只新增，不覆盖。

## 导入步骤

1. 选择“月度计划”或“年度计划”。年度导入选择年份；月度导入不需要选择导入月份。页面上的“列表月份”只筛选下方展示的月度计划，不参与导入校验。
2. 选择填写好的 `.xlsx`、`.xls` 或 `.csv` 文件。文件最大 5 MB；模板说明中的行数上限为 1,000 行。
3. 检查预览中的总行数、可导入数、错误数及逐行错误。完全空白行会忽略；额外列会提示并忽略。
4. 可筛选错误行并下载错误明细 CSV。预览阶段不会写入业务数据库。
5. 只有确认按钮所示的通过行数会新增；数据库中已存在冲突的计划需先处理后重新导入。本功能不覆盖既有记录。

也可点击“手动新建”，填写同一组业务字段。手动新建同样先预览、校验，再由用户确认写入。

年度导入的所有计划入段日期必须在选择的年份内；月度导入可以包含任意年月的有效日期。支持 `2026/10/11` 和 `2026-10-11` 等格式，预览统一规范为 `YYYY-MM-DD`。系统按上海业务日期校验，Excel 日期按工作簿日期系统解析。导入只新增计划，不设置检修状态、审批状态、出段日期或正式排程。
