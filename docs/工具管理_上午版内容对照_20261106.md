# 工具管理：以上午版内容为基准调整页面

基准：2026-11-06 06:43 的提交 `613605e`（`feat: refine tool management workspace`）。后续的 `950a2c9` 主要增加测试。本次不回退数据库，也不删除后来按用户明确要求补充的多选、两库、日期及勾选盘点能力。

2026-11-07：收起重复入口，主表默认仅6个固定入口；选择工具后按状态显示可办理业务。内容保留，位置以本表和最新版使用文档为准。

原则：上午版本的业务内容及状态规则继续使用；修改的是展示位置、查询和操作方式，不因简化界面删掉业务入口。

| 上午版内容 | 当前入口与保留内容 |
| --- | --- |
| 有编号、无编号、套装台账 | 同一张台账，表头按类型筛选；名称、编号、标签分列，账面及可领用数量分别显示。 |
| 借出、归还、未归还查询 | 底部借还操作；业务记录中查询借用类型、人员、数量、预计归还、归还人及实际归还时间，选择单据后可归还。 |
| 调出、接收、取消、调拨历史 | 底部调拨操作；业务记录完整显示两库方向、数量、时间和处理状态。 |
| 送检、维修、校验回库 | 底部检修操作；业务记录分送检、送修，显示单位、原因、时间、结果及证书，未完成单据可登记结果。 |
| 遗失报废申请及审核 | 保留申请、独立审核、意见、处置数量与完整申请详情；业务记录可以查询已批准及已驳回的历史。 |
| 盘点及差异 | 底部仓库盘点及盘点记录；按用户新要求使用左侧勾选表示现场找到，确认后保存差异，可导出。 |
| 低储、定检、超期及设备异常预警 | 业务记录与预警 → 综合预警，保留完整对象、类型、提示和处理入口；不只显示一个预警数量。 |
| 工具字典、分类、低储阈值 | 工具资料内切换字典及分类；保留规格、状态、全库及分库阈值，支持增删改和历史引用保护。 |
| 标签、启停用、检定周期 | 单选实物 → 详情与记录 → 标签与状态；基础资料修改仍可维护检定时间及日期。 |
| 工序工具绑定、防错核验 | 单件详情底部保留工序绑定和作业工具核验入口；借出表单保留关联作业任务，可选项直接显示。 |
| 智能工具柜、无人工具室 | 工具资料 → 智能设施，显示类型、所属库、启用状态、连接状态及最近通信时间，可维护及联调。 |
| 识别、领还、盘点、门禁及异常事件 | 业务记录与预警 → 设施事件，可查来源、结果、内容和处置；异常可记录处理说明。模拟不代表真实设备已连接。 |
| 工具详情、流转追溯、业务导出 | 单件资料与记录保留；业务记录可查询所有工具的单据；导出业务记录包含台账、借还、调拨、检修、审批、预警、事件及审计。 |

与上午版本不同、但来自用户后续明确要求的内容：工具库固定为检修工具库和整备工具库；取消管理方式下拉框；可选信息直接显示；操作放列表下方；支持多选、表头过滤、入库与最后检修日期、基础资料增改删、勾选盘点与结果导出。这些不按旧代码机械回退。

验证：`node tests/tool_workspace_ui.mjs` 使用独立 PostgreSQL 测试数据区，覆盖主台账以及业务单据归还、调拨接收、维修结果、独立审核、异常处置、设施状态、工序绑定、导出等实际浏览器操作。生产演示库不参与测试写入。
