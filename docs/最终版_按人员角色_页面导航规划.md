# 高级修检修车间信息化系统——按人员角色划分的页面导航（最终版规划）

> 依据：`高级修检修车间信息化需求_逐条对应人员.xlsx`，Sheet1 第 2～213 行。
> 此文档规划的是需求表所指向的**最终版功能导航**，不代表当前程序已实现。只做页面/菜单归属，不修改需求、流程或数据库。

## 导航设计原则

1. **进入系统先选择角色**。每个角色拥有独立侧边导航，界面中文为主。
2. 菜单按 **一级功能区 → 二级页面** 展示；需求里的按钮、筛选项、审批节点不一定单独作为页面。
3. 所有角色可有通用的“工作台/消息/我的待办”，但它们只是共用布局，不算新增业务需求。
4. 原表角色是**主要功能归属**，跨角色的派工、审批、质检、交接可通过共享单据串联，不意味着其他角色没有查看权限。
5. 原表“配件”与“备件/物料”按文档原语义分开呈现，不做不经确认的合并。
