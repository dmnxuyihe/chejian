## 首次登录与交接

1. 本机打开当前运行的网站。已有业务数据保留，不重新导入。
2. 若没有账号，出现“初始化账号”：填写账号、真实经办姓名、至少12位密码。首次账号只能从服务所在电脑的 localhost / 127.0.0.1 地址创建。
3. 账号及密码散列存 PostgreSQL 的 `login_users`；8小时会话的令牌散列存 `login_sessions`。Cookie 使用 HttpOnly 与 SameSite；HTTPS 下增加 Secure。
4. 其他使用者需要独立账号。由本机维护人员在项目目录运行 `npm run auth:user`，按提示录入，不将密码写入代码或命令行参数。
5. 退出后原会话失效。会话失效后办理时要求重新登录，经办人由实际重新登录的账号确定。
6. `npm run db:init` 及服务器启动会幂等创建这两张登录表。数据库完整备份应包含它们；它们不计入原30张业务表的展示数量。

通用状态保存接口不允许绕过工具业务接口覆盖工具台账和工具审计记录。离线本地模式没有账号数据库，不代表已验证身份；本次验收针对 PostgreSQL 网站。
