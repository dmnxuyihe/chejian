# 工具管理界面简化

2026-11-13。本次修改的是实际网页的信息组织和操作入口，不涉及新增角色、业务规则或数据库清空，也不录制视频。

## 实际界面变化

1. 工具台账默认只展示已登记实物和套装。原库存通过“待完善登记”进入，仍支持接管登记；数量未删除或改写。两种登记范围之间切换会清空原选择并提示，防止把两种不同任务混在一次办理中。
2. 搜索区只放名称/编号/条码、工具库、状态以及查询/重置。新增、导出和选中工具的操作集中在列表下方。
3. 未选工具时不展示整排灰色业务按钮。选中后明确展示所选工具、当前状态和筛选外选择；同一范围跨搜索多选仍保留。
4. 待归还、待接收调拨、待登记检修结果、待审核分别放入“待完成业务”；新的借出、调拨、送检、送修、遗失、报废申请放入“办理业务”；修改、状态与删除等放入“资料维护”。可用操作保留明确名称，不能办理的原因按需展开。
5. 点击名称或编号先查看只读档案，包含当前位置、库存、借用人、入库时间、最后检修时间、检定及历史。修改使用底部“修改资料”，不再把查看和编辑混在一起。
6. 五类业务记录页面及其查询弹窗不再直接办理借还、调拨、送检送修结果或处置审核，只展示详情和“到工具台账”。链接按具体实物定位；多成员借用单定位到对应成员，不自动勾选或提交。
7. 预警页移除直接送检、归还及批量提交入口，保留查询并定位到台账。在台账明确选择工具后，仍可批量办理。统计、预警口径和领域校验保持。
8. 业务记录默认只展开业务类型、状态和关键词；经办人、时间和工具库等查询条件按需展开，已有筛选与导出能力保留。混合检修回执继续分别定位到送检/送修记录。

设施事件的异常处置仍保留在现有事件记录中；本次统一的是工具库存流转业务入口，没有删除设施联调能力。

## 操作主线

查找工具 → 勾选工具 → 查看当前状态和待完成业务 → 从台账办理 → 就地查看状态变化。

送检示例：在库工具勾选后“送检” → 送检中再次勾选 → 下方“待完成业务 / 登记检修结果” → 选择本次单据、填写结果与证书 → 确认回库。业务记录安排在最后查询证书、经办人和时间。
