# 工具管理第四至六轮：修复与回归记录

日期：2026-11-13。范围为工具管理现有功能与月度计划合版兼容；本轮未增加角色、导航分组或无关业务。

前面三轮确认的 H01–H06、I01–I04、K01–K03 共 13 项，已修复并通过对应回归。原研究报告保留检测当时的证据，不覆盖历史记录；本文件记录修复后的状态。

## 逐项结果

| 编号 | 已修复的行为 | 验证重点 |
| --- | --- | --- |
| H01 | 套装未勾选成员的数量输入禁用，不参与保存校验 | 未选成员数量为 0 时仍能正常更名；已选成员继续校验正整数 |
| H02 | 套装明确显示成员库位，以所选工具库过滤成员 | 异库成员不可选择；主动切库后清除异库勾选，只显示目标库成员 |
| H03 | 盘点保留“已发送未确认请求”和后续草稿，先确认原请求，再保存新修改 | 慢响应、已提交后丢响应、期间继续编辑、整页刷新恢复；真实他人修改仍被拦截 |
| H04 | 批量公共文本仅传一份，服务器在同一事务内应用到每项 | 100 项、单位 120 字、原因 500 字完整保存；最后一项失败时前项全部回滚；重复请求只办理一次 |
| H05 | 套装自身及其成员身份以分组核对，避免成员数量撞到扁平数组上限 | 301 成员套装更名、借出、整套归还；成员替换和组成变化继续被拒绝 |
| H06 | 失效提示包含工具编号，支持明确移除失效项并保留其余填写内容 | 失效时不提交任何部分业务；保留领用人、时间、经办人；用户重新确认后才办理有效项 |
| I01 | 系统生成的有限数值按数值文本导出，负差异不额外加撇号 | -2 和正差异可直接按数值解析；普通文本继续保留原有处理 |
| I02 | 切换阈值适用库时回显该范围的已有值，未配置范围显示空白 | 全库 2、分库 6 正确回显；更名不误改阈值；未填写的分库配置不自动创建 0 |
| I03 | 分类、工具字典、设施及工序绑定保留事务内前后快照 | 删除后按原编码查到记录和明细；已有引用保护继续有效；不伪造旧日志 |
| I04 | 并发冲突后读取最新业务状态，显示完成者、时间、结果及记录入口 | 已完成或取消的单据停止重提，不覆盖他人结果；仅无关资料变化时保留输入，允许核对后再次确认 |
| K01 | 现有工序绑定可明确解除，并记录原绑定信息 | 新增 2、修改为 3、解除全过程；同一绑定不重复新增，删除后需求不再存在 |
| K02 | 过期以实际时刻判断；预警文字统一 30 天，日期使用一致的本地展示 | 刚过期、恰好到期、7/20/30 天边界；页面与预警文字一致，过期禁借不变 |
| K03 | 具体预警编号使用实物 ID 精确定位台账，突出目标行 | 同前缀两项只定位所点工具；不自动勾选或办理；清除定位后普通搜索仍支持包含匹配 |

需求对应沿用前面研究报告：第 156 行基础资料、第 157 行台账、第 158 行借还、第 159 行调拨、第 160/161 行送检送修、第 163 行盘点、第 164 行预警，以及用户补充的基础资料增删改与直观操作要求。工序绑定、精确定位等属于现有功能的维护与交互改进，未将它们宣称为需求表新增的独立条目。

## 回归与停止条件

本轮按“修复—定向复测—扩展相邻分支—全量回归”循环执行。过程中修正了异库成员被样式重新显示、嵌套弹窗导入缺失，以及丢响应恢复时错误采用他人最新进度版本等问题；这些均已重新验证。

- 新增回归：5 组领域检查、19 个浏览器检查点，共 24 个检查点，覆盖上述 13 项及相邻分支。
- 工具完整测试：通过，包括 1000 个领域场景 / 6100 个断言、100 组浏览器用户流程、140 个功能页面入口及既有工具专项测试。场景数、断言数和缺陷数是不同口径，不相加。
- 前两轮修复回归：context-fixes、followup-fixes 通过，包含筛选状态、日期、删除追溯、部分归还、跨页盘点保存及旧对象保护。
- 月度计划测试和功能导航测试通过，未观察到工具修改覆盖月度审批或发布记录。
- 实际新版服务：桌面 1366×860、手机宽度 390×844，各走六个工具页面，共 12 个页面检查；无页面脚本错误、无整页水平溢出。横向数据表仍可在自身容器内滚动。
- 最后一轮上述检查通过，当前清单没有未解决的已知问题。本结论限定于已验证的软件需求和场景，不表示所有未来输入、设备与部署环境都不会出错。

## 数据与运行方式

全部业务测试写入随机命名的隔离 PostgreSQL schema，结束后清理。正式数据库前后均为 revision 65，内容 SHA-256 均为 `19aff118e58c7b4ce864b43498bd8bfab946bfca6c3c29f4eb05cd97a2aba65e`。实际页面检查只读，没有导入、删除或重置正式数据。

本机新版预览入口：`http://127.0.0.1:5196/#/functions/assets/tool-register`。此入口使用本次修复后的前后端及原 PostgreSQL 数据库。

执行本轮新增回归：

```powershell
npm run test:tools:rounds-fixes
```

默认不依赖正在运行的网站。若还要核对正式站点测试前后不变，可指定只读核验地址：

```powershell
$env:TOOL_FORMAL_BASE = 'http://127.0.0.1:5196'
npm run test:tools:rounds-fixes
```

完整复测命令：`npm run test:tools`、`npm run test:tools:context-fixes`、`npm run test:tools:followup-fixes`、`npm run test:monthly-tools`、`npm run test:navigation`。
