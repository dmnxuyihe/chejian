# 工具管理页面修改建议落实（2026-11-12）

依据用户提供的《工具管理页面修改建议.docx》及其中布局参考图调整。用户要求先搁置遗失报废是否取消审核的分歧，因此仍保持原申请、独立审核及持久化流程。

| 建议 | 本次结果 |
| --- | --- |
| 六个菜单 | 工具看板、工具台账、工具盘点、业务记录、工具预警、工具资料；旧路径仍兼容 |
| 工具看板 | 实际工具数量、可用数量、借出、检修占用、30天送检预警、库存预警；展示到期清单、库存清单和最近8条操作日志 |
| 台账查询精简 | 移除连续扫码、借用类型、送检送修单位查询；新增、导出移至查询行；清理旧浏览器隐藏条件 |
| 台账列和布局 | 保留名称、编号、类型、工具库、条码、账面、可用、状态、入库时间；取消水平冻结；查询、列表、业务操作顺序排列；所选工具、办理回执和不可办原因在下方 |
| 名称/编号编辑 | 点击进入编辑，显示可选日期；从编辑页打开完整档案或删除；业务引用保护仍生效 |
| 台账状态 | 查询标签使用在库、借出、送检、送修、调拨、报废、遗失、待登；详细限制仍保留在档案和按钮提示中 |
| 业务记录 | 五类业务：借还、调拨、送检、送修、遗失报废；状态筛选为办理中/已完结；增加经办人、办理起始时间；与台账同样通过查询按钮应用条件 |
| 操作日志和设施事件 | 从业务记录的独立链接查看，保留异常处置及原审计明细，不混入业务类型筛选 |
| 工具预警 | 独立查询送检、库存预警；送检支持多选和批量办理，数量不足/已占用工具不可选；数据来自同一工具库存与检定日期 |
| 盘点和工具资料 | 内容不改，保留原清点、进度保存、导出和资料增删改 |
| 遗失报废取消审核 | 暂不执行，等待用户明确新旧需求取舍 |
| 经办人自动取登录账号 | 尚未实施：当前功能版没有登录会话或认证用户接口，不使用虚构的固定用户替代真实登录身份；仍要求填写经办人 |

## 验证

- 隔离 PostgreSQL + Edge 实际创建工具、借出/归还、经办人及起始时间查询、预警多选送检、日期编辑入口、删除引用保护、盘点及资料维护。
- 100组浏览器流程、1000组领域组合（6100断言），既有混批回执、检修拆分来源、独立审核、盘点离线与并发保存继续回归。
- 1366×768、1024×800、390×844检查四个变化页面；桌面台账查询、列表和操作默认可见，窄屏表格独立横向滚动，不导致整个页面横向溢出。
- 测试数据写入隔离 schema；不改正式演示库。

当前没有接入真实 RFID/工具柜/门禁，本次不改变原设备接口能力。
