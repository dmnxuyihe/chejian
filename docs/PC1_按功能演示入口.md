# PC1按功能演示入口

启动现有项目后打开 `/demo.html`，自动进入 `#/demo/calendar`，无需选择角色。该入口使用同一后端和真实 PostgreSQL 数据，没有复制另一套业务状态。

顶部仅保留五个功能入口，顺序依据《2026-10演示.docx》：

1. 月度计划：默认打开月度日历，区分计划入段与正式排程预计出段。右上角“导入月度计划”进入上传、预览、确认；支持下载模板。
2. 检修排程：选择相邻日期的两辆机车，校验人员、工具和物料，模拟 C5 构架与轮驱流程；拖动或精确调整时间、锁定、重新模拟，再确认发布。班组清单作为本功能的下级页面保留。
3. 单车查询：选择同一辆机车，查看每日任务日历、甘特图、人员工时及工具物料清单。调整链接返回本入口内的排程页面。
4. 车间日历：查看两辆车每天的任务，可按车筛选。演示入口只保留车间每日任务，单车查询与甘特图在“单车查询”展示；完整角色页继续保留其他原有视图。
5. 整车管控：列出车辆正式版本的全部任务状态，完成任务可查看数据、图片与视频；可展开工位进度。此入口不显示上传记录或记录入段上台等现场操作。

PC2/PC3/PC4的三维展示、执行操作和外部联动并未由这个入口新增或模拟；管控页读取现有后端状态，跨端联动仍需要对接真实执行端。

原有角色入口继续可用，角色选择页增加“PC1功能演示”直达链接。免安装打包脚本也会复制 demo.html。

当前界面采用减法设计：去掉新增的左侧栏、车辆概览、进度环、统计区、任务搜索与筛选、重复说明及“下一步”引导。页面仅保留功能导航、标题、必需操作和业务内容。五页标题区使用同一张透明背景机车检修简笔线稿，导航使用对应功能小图标；线稿不包含数据、不接收点击，也不增加业务操作。整车管控直接显示车辆选择及任务表；完成任务可查看原有记录。

月度导入只保留文件导入和模板下载，不显示只有一个选项的导入类型选择。月度日历仅保留月份切换与入段/出段查看，移除演示不需要的机型、修程、车号筛选和当日统计框；完整角色页继续保留原查询能力。排程保留选车、最晚时间、资源预检、模拟、调整锁定和发布；去掉样例数据菜单及资源重复入口。车间页不再重复放置顶部已有的跨页导航。安全校验、错误提示、图例、模拟/正式状态及原有角色页面继续保留。

界面验证：`python tests/demo_visual_ui.py`，覆盖1440/1024/768/390px页面、冗余内容已移除、只读记录弹窗、两种主题的关键文字对比度及原库未变检查。视觉证据在 `test-artifacts/demo-ui-polish`；有效窄屏模拟不代替实体设备或读屏审计。

验证：运行 `python tests/demo_function_ui.py`。测试对正式数据库只查询，对导入和排程使用独立测试 schema，结束自动删除。覆盖五个功能及两个子页、无角色导航、内部链接、真实导入及模拟确认、只读记录、刷新、桌面/平板/窄屏和键盘导航。

线稿资源：`src/assets/pc1-header-lineart.png`，由 imagegen 在原机车插画基础上简化生成，RGBA透明PNG；作为装饰性CSS背景使用，不承载标题、数据或交互，原始插画保留。

交互控件统一使用圆角描边、分段页签与明确的悬停、选中、禁用和键盘焦点状态；日期选择、勾选框、资源切换、甘特图拖动及锁定菜单同步整理。所有业务行为保持原有逻辑，样式限定在演示入口。

日历继续统一为浅蓝入段、浅绿出段/正式任务及文字状态，放大事件字号；月份切换和常用操作采用线条图标。单车日历点击任务可选择对应日期并更新当日任务表；查询甘特图可点击查看任务详情，完整名称和时段也可悬停查看，时间调整在检修排程完成。

排程甘特图行菜单扩大了可点击区域，并给弹窗关闭按钮统一线条图标；单车任务日历省去重复车号，让工序和计划状态更容易扫读。

单车日历采用日历与当日明细并列的布局：左侧选日期，右侧用简洁时间线列出工序、完整起止时间、工位、模拟/正式标记与任务状态。较窄屏幕自动上下排列；任务较多时明细区域可滚动。没有任务的日期显示空状态，未排程车辆的“跳到首项任务”按钮禁用。

操作按钮使用原创 SVG 简笔图标：折角文件表示导入/下载、小甘特图表示模拟、勾选单据表示发布、日历勾选表示首项任务，小锁表示锁定/解锁。图标采用圆头线条和淡色填充，缩放保持清晰；图标为装饰，按钮文字继续提供操作名称。主按钮、次按钮、悬停和按下样式同步统一。

排程生成模拟后，整体方案操作移到甘特图上方，右侧为所选任务详情。点击任务名称或甘特条即可选中，右侧可填写分钟级开始时间、调整并锁定或解锁；重新模拟保留任务选择和已锁时间。拖动显示实际吸附后的时间，Shift改为1分钟微调，时间刻度支持进一步放大，取消拖动不改数据。

单车查询中的日历事件、当日任务名称和甘特条可打开同一任务详情，显示计划起止、工位、实际起止（已有记录时）、班组需求和已派人数、每人工时、已分配人员、工具物料需求和用量依据。人员来自当前模拟或正式任务对应的分配记录；计划工时与工序历时分别显示，不冒充实际工时。

随包新增计划演示表以 `demo-materials/01_计划导入` 为准，打包时覆盖旧演示表。当前车号为 HXD1C-DR1102A/B，入段日期为2026年11月2日/3日，导入列表月份和排程日历均选择2026年11月，建议最晚完成2026年11月30日18:00。Excel和备用CSV只导入其中一份；再次演示需要同时更换两个车号，只改日期可能仍被未完成计划拦截。打包前会对源数据库做只读导入预览，出现重复或其他错误即停止打包。
