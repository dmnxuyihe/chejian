# 工具管理第三轮检测修复（2026-11-13）

对应 research_tools_followup_20261113/检测报告.md 的 G01–G07。原报告与截图作为修复前证据保留，没有覆盖。

| 问题 | 修复后的行为 |
| --- | --- |
| G07 旧对象被新工具替代 | 实物、套装等使用持久化递增标识；旧数据缺少计数器时结合现存记录和已保留的创建指令初始化，删除最高编号也不复用。新增实物和套装有不可变身份；选择记住身份。旧表单携带原对象核对信息，服务端在事务内验证。工具已删除、被替换或套装组成变化时拒绝提交，保留表单输入并提示重新选择，不自动指向新工具。 |
| G06 切页后盘点同步失效 | 草稿、待同步内容、请求、计时器和保存状态按盘点单独立维护。后台完成的保存更新对应盘点上下文；切回来显示正确的已保存状态，继续修改使用最新进度版本。真实旧版本冲突仍被拒绝。 |
| G01 部分归还数量重置 | 是否勾选与数量分离。取消勾选不抹掉已填数量；重新勾选及全选切换保留部分归还数量。未勾选行不提交。 |
| G02 零数量归还定位不足 | 已勾选行要求 1 至可归还上限的整数；零、负数、空白、小数及超量直接标红并阻止确认，取消选择该行后不影响其他有效行。修正后可正常提交。 |
| G05 盘点 CSV 时间遗漏 | 盘点导出的确认时间经过同一时间显示函数，与本机时区下的页面一致，不简单删除 UTC 标记，不修改历史时刻。 |
| G03 当前借用单不明确 | 从借用记录进入详情，标题显示单号，正文显示当前领用人；该单借出及归还行在全部流转中高亮并带 aria-current。保留原工具完整历史。 |
| G04 超期预警入口深 | 在现有“工具预警 → 预警类型”中提供“借用超期”。可查单号、工具、领用人和工具库，显示应还时间及未还数量，直接打开原有归还表单；归还结清后移出队列。有关联待处理申请、无可归还数量时明确说明。 |

没有增加左侧菜单，没有调整遗失报废审核政策，没有将软件模拟当作实际硬件联调结果。
