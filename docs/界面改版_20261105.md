# 调研后的第一轮界面改版

本轮调整页面布局与操作呈现。公共入口继续按功能组织，保留模拟、校验、锁定、确认发布及数据库保存的既有流程。

## 已修改

- 主站和独立演示页的桌面顶部区域收紧；标题与插画缩小，取消演示页的大横幅插画。首页五项主线改成紧凑入口。
- 主站公共色板与独立演示页对齐，保留蓝灰和青绿的明暗主题。
- 排程顶部为整体方案摘要：车辆数、任务数、期限、重新模拟、确认发布。车辆及资源条件按需展开；冲突时原因默认展开，未校验通过仍不能发布。
- 甘特视图控制放在图表上方。时间刻度使用“全程概览／按日／按小时”名称；缩放以当前任务为定位依据，保留纵向滚动。
- 任务行的最小高度由88px改为56px，长名称仍可换行。短任务条隐藏放不下的文字，名称与时间始终保留在左侧可点击任务行中。
- 当前任务详情支持收起、重新选择后打开、展开完整资源清单。任务名和车号位于精确时间编辑之前；时间输入与锁定规则保留。
- 基础资源页移除第二层标题、字段介绍与重复插画，采用资源类型、搜索、状态筛选、数量和表格。搜索按名称、编码、班组等显示字段匹配；编辑仍直接可见，删除位于“更多”中。
- 资源状态仅在显示时转为中文，数据库状态值保持不变。筛选后重新绑定当前结果行的编辑与删除操作；资源编辑表单关联标签与输入控件。

## 检查记录

- `node tests/workspace_layout.mjs`：通过渲染和事件处理单元检查，覆盖40项任务、详情收起与重新打开、缩放定位、待校验方案禁止发布、资源组合筛选、结果行绑定及输入转义。
- `node tests/pc1_simulation.mjs`：35项断言通过，覆盖两车模拟、资源、调整锁定、重新计算、确认和历史。
- `node tests/phase_one_roles.mjs`：内部功能配置检查通过；这些内部模块名称不改变公共导航按功能组织的方式。
- 生成的首页、排程、独立演示、冲突、选车、资源页面HTML检查了标签配对、ID唯一和标签引用。CSS只做结构与规则优先级核对，不视为浏览器样式验收。
- 本地5193端口提供上述新文件，配置接口显示仍使用PostgreSQL。本轮没有向在线数据库提交演示操作或迁移数据。

## 尚未验证

工作设置禁用了浏览器控制，本轮未进行浏览器截图、实际拖动、键盘全流程、屏幕阅读器或不同宽度的视觉验收。事件单元测试中的尺寸是测试替身参数，不是实测界面尺寸。不能据此宣称首屏六项任务、无溢出或可用性改善目标已经通过。

导航的进一步整理、执行页面的任务状态布局等仍属于后续改版；本轮不宣称全站内容模板已经重做完成。
