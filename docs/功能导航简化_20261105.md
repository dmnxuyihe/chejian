# 功能导航简化 · 2026-11-05

接续《界面改版_20261105》，将完整网站的默认入口从功能门户改为月度计划。打开主站即可开始业务，目录只在需要查找功能时打开。

## 公共导航

只保留一套侧栏。五个业务组一次展开一组，默认展开当前功能所在组。桌面可以收起侧栏；窄屏使用抽屉，提供关闭按钮、遮罩与 Escape 处理，打开时设置主内容 inert，并限制 Tab 在抽屉内循环。

| 分组 | 功能入口 |
| --- | --- |
| 计划与排程 | 月度计划、计划导入、检修排程、任务下发 |
| 作业与验收 | 任务派工、检修作业、检修专检、检修验收 |
| 查询与管控 | 单车查询、车间日历、整车管控、执行跟踪、车间进度监控 |
| 资源台账 | 基础资源台账、配件台账、工位与资源占用、基础资源总览 |
| 工艺配置 | 修程与工序 |

删除默认入口中的五项快捷卡片、顶部重复业务导航、分类按钮和规划项列表。侧栏底部保留“全部功能”，目录为五组普通链接，可搜索。搜索“工具”“设备”“物料”等同义入口会找到基础资源台账，资源类型继续在台账页内切换。

19个导航入口覆盖28个已实现的功能路由。工具管理的7个页面归并到一个入口，设备、物料的共用资源台账与配件的共用台账各归并到对应入口；业务页面和原有链接保留。134条原功能地址及其来源地址继续解析，106个规划项不进入侧栏或目录，但保留旧直达地址兼容。这不表示规划项已经实现。
