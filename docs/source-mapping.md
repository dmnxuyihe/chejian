# Source Mapping

本工程开发时遵循三个数据 / 流程来源和一个视觉参考来源。

## Database Structure

来源：`智能排程+配件(1).xlsx`

用途：

- 第一版数据库结构理解
- 排程核心表关系
- 配件新增结构：类型、实例、任务需求、排程分配、流转

原则：配件只做排程必需补充，不替代原有备件。

## Process Definition

来源：`构架_轮驱检修流程(1).xlsx`

用途：

- 构架与轮驱任务名称
- 流程先后顺序
- 标准工时参考
- 任务步骤提示

原则：页面不提供任意新增 / 删除 / 重排流程节点的能力。

## Frozen Initial Data

来源：`构架_轮驱_冻结数据库结构_初始化数据 (1).xlsx`

用途：

- 班组
- 人员
- 工位
- 设备
- FS 依赖
- HXD1C0001 计划
- 初始化排程
- 初始化人员分配
- 工作日历

## UI Reference

参考：用户提供的 production-dashboard / inventory 页面风格。

实现方式：保留类似的工业后台布局、浅色卡片、侧边导航、KPI、表格与排程信息密度，但工程本身使用无第三方依赖的 ES Modules + CSS，避免安装依赖后才能启动。
